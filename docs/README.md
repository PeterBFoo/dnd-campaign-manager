# Documentación

La documentación del proyecto forma parte del mismo repositorio que el código y debe actualizarse en el incremento que introduce cada cambio.

## Secciones

- [`adr/`](adr/README.md): decisiones arquitectónicas aceptadas, sustituidas o rechazadas.
- [`specs/`](specs/README.md): especificaciones funcionales, planes de implementación y tareas.
- `architecture/`: vistas generales y diagramas de arquitectura.
- `runbooks/`: procedimientos de despliegue, restauración y respuesta ante incidencias.

## Regla de mantenimiento

Una tarea no se considera terminada si cambia el comportamiento, la arquitectura, la operación o el despliegue y no actualiza la documentación correspondiente.
